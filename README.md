# C2 Coach — โครงแอปฝึกภาษาอังกฤษสู่ CEFR C2 (แผน 24 เดือน)

แอปสำหรับผู้ใช้คนเดียว ทำงานในเบราว์เซอร์ทั้งหมด ไม่มีเซิร์ฟเวอร์ ไม่มีการล็อกอิน ข้อมูลเก็บในเครื่อง (IndexedDB)
สถานะ: **โครง (skeleton)** — ทุกโมดูลเปิดได้ บันทึกข้อมูลได้ และทำงานครบวงจรด้วย AI จำลอง รายการที่ยังต้องทำอยู่ใน `TODO.md`

## การตัดสินใจที่เลือกไว้ (อ่านก่อน)

1. **Vanilla JavaScript (ES modules) ไม่มี framework ไม่มี CDN ไม่มีขั้นตอน build** — วางทั้งโฟลเดอร์แล้วใช้ได้เลย และทำงานออฟไลน์ได้
2. **ไฟล์ข้อมูลเป็น `.js` ใน `js/data/`** (ไม่ใช่ `.json`) เพื่อใส่คำอธิบายภาษาไทยกำกับได้ และแก้ไขได้โดยไม่ต้องแตะโค้ดส่วนอื่น
3. **ค่าเริ่มต้นคือ AI จำลอง (Mock)** คะแนนจากโหมดจำลองมาจากการนับคำเท่านั้น จึงติดป้าย "จำลอง" ทุกที่ และ**ไม่ถูกนับ**ในเรดาร์หรือสถานะ C2-ready
4. **API key เก็บในเบราว์เซอร์นี้เท่านั้น** ไม่ถูกเขียนลงไฟล์ใด และไม่รวมอยู่ในไฟล์สำรอง
5. **กฎการให้คะแนนบังคับด้วยโค้ด** (`js/scoring.js`) ไม่ได้พึ่ง prompt อย่างเดียว:
   - หลักฐาน (quote) ต้อง**พบจริงในข้อความ** ถ้าไม่พบ เกณฑ์นั้นเป็น "ประเมินไม่ได้" และไม่มีคะแนน
   - ระดับรวม = `min(ปัดเศษค่าเฉลี่ยถ่วงน้ำหนัก, คะแนนเกณฑ์ต่ำสุด + 1)`
   - จุดอ่อนที่ไม่มีหลักฐานจะถูกตัดทิ้ง และไม่บังคับจำนวนจุดอ่อน
   - เกณฑ์ที่ไม่เกี่ยวกับงาน (เช่น Source synthesis ในงานที่ไม่มีแหล่งข้อมูล, Interaction ในงานพูดเดี่ยว) เป็น N/A แล้วกระจายน้ำหนักใหม่
6. **C2-ready** = งาน 3 ชิ้นล่าสุดของทักษะนั้นผ่านติดต่อกัน (รวม ≥ 85, ไม่มีเกณฑ์ใด < 4) และเป็นงาน 3 ประเภทที่ต่างกัน โดยนับเฉพาะ**การส่งครั้งแรก**ของแต่ละงาน (ฉบับ Redo ไม่นับ เพราะได้เห็น feedback แล้ว)
7. **การออกเสียง/ทำนองเสียงยังประเมินไม่ได้** เพราะ AI เห็นเพียง transcript งานพูดจึงขึ้นว่า "ประเมินได้ไม่ครบ" และยังเป็น C2-ready ไม่ได้ จนกว่าจะเพิ่มตัววิเคราะห์เสียงในเฟส 3
8. **ไม่เก็บไฟล์เสียงลงฐานข้อมูล** เก็บเฉพาะ transcript ที่ผู้ใช้ตรวจแก้แล้ว เพื่อให้ไฟล์สำรองมีขนาดเล็ก
9. **Redo loop**: หลังส่งครั้งแรกจะเห็นคะแนน หลักฐาน และจุดที่ควรแก้ แต่ตัวอย่างการเขียนใหม่และคำเฉลยของข้อผิดพลาดจะถูกล็อกจนกว่าจะส่งฉบับแก้ไข
10. **วลีเป้าหมายไม่เกิน 2 วลีต่องาน** และนับว่าผ่านเมื่อผู้ประเมินระบุว่าใช้ได้เป็นธรรมชาติเท่านั้น
11. **ชั่วโมงตามแผน** = ชั่วโมงต่อสัปดาห์ × 48 สัปดาห์ × 2 ปี (ค่าเริ่มต้น 9 × 48 × 2 = 864 ชั่วโมง) กระจายเป็นเส้นตรงตลอด 24 เดือน แดชบอร์ดแสดงส่วนต่างจริงและไม่รับประกันว่าจะถึง C2
12. **วันเริ่มแผน** คือวันที่เปิดแอปครั้งแรก แก้ได้ในหน้าตั้งค่า
13. **Can-do 48 ข้อ บทอ่าน โจทย์ และบทฟัง เขียนขึ้นใหม่ทั้งหมด** ตามแนว CEFR Companion Volume ไม่ได้คัดลอกข้อความจากเอกสารต้นฉบับหรือข้อสอบจริง
14. **ข้อสอบจำลองมีเฉพาะรูปแบบและตัวจับเวลา** ผู้ใช้ทำข้อสอบตัวอย่างทางการของผู้จัดสอบเอง แล้วบันทึกคะแนนในแอป
15. **แบบฝึกฟังตัวอย่างใช้เสียงสังเคราะห์ของเบราว์เซอร์** เพื่อทดสอบโครง รองรับ `audioUrl` สำหรับไฟล์เสียงจริงแล้ว
16. **Service worker แบบ network-first**: ออนไลน์ได้ไฟล์ล่าสุดเสมอ ออฟไลน์ใช้สำเนาในแคช
17. **ชื่อโมเดลเริ่มต้น `claude-sonnet-5-5`** แก้ได้ในหน้าตั้งค่า

## สิ่งที่ทดสอบแล้ว และยังไม่ได้ทดสอบ

ทดสอบอัตโนมัติด้วย Chrome แบบ headless (จอมือถือ 390 px และจอ 1200 px):

- เปิดได้ทุกเส้นทาง (18 เส้นทาง) ไม่มี error ใน console
- งานเขียน: ส่ง → ผลประเมิน → ตัวอย่างถูกล็อก → ส่งฉบับแก้ไข → ปลดล็อก → ส่งวลีเข้าคลัง → เก็บข้อผิดพลาด
- คลัง: ทบทวนแบบ SM-2, เพิ่มวลีเอง, วลีเป้าหมาย 2 วลีปรากฏในงานถัดไป
- แบบฝึกอ่าน/ฟัง: จับเวลา ตรวจด้วยเฉลย บันทึกผล
- งานพูด (ไมโครโฟนจำลอง): อัด → แก้ transcript → คำถามแย้งจากกรรมการ → ผลประเมิน
- สำรอง → ล้างข้อมูล → กู้คืน → โหลดหน้าใหม่ ข้อมูลครบ
- กฎการให้คะแนน 7 ข้อ (เพดานระดับ, หลักฐานปลอม, N/A, โหมดจำลองไม่ผ่าน, C2-ready)
- เส้นทาง Claude API ด้วย**คำตอบจำลอง**: header, รูปแบบคำขอ, การอ่านผล, กรณี key ผิด (401)

**ยังไม่ได้ทดสอบ:**

- การเรียก Claude API ด้วย key จริง (ทดสอบได้เพียงกับคำตอบจำลอง) — ทดสอบครั้งแรกด้วยงานสั้น ๆ ก่อน
- การถอดเสียงอัตโนมัติ (Web Speech API) บนอุปกรณ์จริง — Chrome บน Android และเดสก์ท็อปรองรับ, Firefox ไม่รองรับ, Safari บน iOS รองรับบางส่วน ถ้าไม่รองรับ แอปให้พิมพ์ transcript เองได้
- การติดตั้งเป็น PWA และการใช้งานออฟไลน์บนมือถือจริง

## วิธีเปิดใช้งาน

แอปใช้ ES modules จึง**เปิดด้วยการดับเบิลคลิก `index.html` ไม่ได้** ต้องเปิดผ่านเว็บเซิร์ฟเวอร์

### ทดลองในเครื่อง

```
cd c2-coach
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

### GitHub Pages

1. สร้าง repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมด**ในโฟลเดอร์ `c2-coach`** (ให้ `index.html` อยู่ชั้นบนสุดของ repository)
2. ไปที่ Settings → Pages → Source เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วบันทึก
3. รอสักครู่ แล้วเปิดลิงก์ที่ GitHub แสดง

### Netlify

ลากโฟลเดอร์ `c2-coach` ไปวางที่หน้า Deploys ของ Netlify ไม่ต้องตั้งค่า build

> ที่อยู่เว็บต้องเป็น `https://` จึงจะใช้ไมโครโฟนและติดตั้งเป็นแอปได้ (GitHub Pages และ Netlify เป็น https อยู่แล้ว)

## การสำรองข้อมูล (สำคัญ)

ข้อมูลทั้งหมดอยู่ในเบราว์เซอร์ของเครื่องที่ใช้เท่านั้น ถ้าล้างข้อมูลเบราว์เซอร์ ถอนการติดตั้ง หรือเปลี่ยนเครื่อง **ข้อมูลจะหาย**

- **สำรอง:** ตั้งค่า → "ดาวน์โหลดไฟล์สำรอง (JSON)" แล้วเก็บไฟล์ไว้ใน Google Drive หรือที่ปลอดภัย แนะนำสัปดาห์ละครั้ง แดชบอร์ดจะเตือนเมื่อเกิน 7 วัน
- **กู้คืนหรือย้ายเครื่อง:** ตั้งค่า → เลือกไฟล์สำรอง → "กู้คืนข้อมูล" ข้อมูลปัจจุบันจะถูกแทนที่ทั้งหมด
- ข้อมูลผูกกับ**ที่อยู่เว็บ** ถ้าย้ายแอปไปอยู่ที่อยู่ใหม่ ต้องสำรองจากที่เดิมแล้วกู้คืนที่ใหม่
- ไฟล์สำรองไม่มี API key ต้องใส่ใหม่ในเครื่องใหม่

## การเชื่อมต่อ Claude

1. สร้าง API key ที่ Claude Console และ**ตั้งวงเงินจำกัด**ไว้
2. ในแอป: ตั้งค่า → ผู้ให้บริการ "Claude API" → วาง key → บันทึก
3. ป้ายมุมขวาบนจะเปลี่ยนเป็น "AI: Claude"

ข้อควรระวัง: แอปเรียก API จากเบราว์เซอร์โดยตรง ผู้ที่เข้าถึงอุปกรณ์นี้ได้จึงอ่าน key ได้ อย่าใช้บนเครื่องสาธารณะ และอย่าใส่ key ลงในไฟล์ของแอป

## การแก้ไขและเพิ่มเนื้อหา

| ต้องการ | แก้ไฟล์ |
|---|---|
| เพิ่มโจทย์เขียน/พูด/Mediation | `js/data/tasks.js` |
| เพิ่มบทอ่านหรือบทฟัง | `js/data/reading.js`, `js/data/listening.js` |
| เพิ่ม Can-do | `js/data/cando.js` |
| ปรับแผน เฟส ตารางรายสัปดาห์ จุดตรวจ | `js/data/plan.js` |
| ปรับเกณฑ์หรือน้ำหนัก | `js/data/rubrics.js` (น้ำหนักแต่ละ rubric ต้องรวมได้ 100) |
| เพิ่ม AI provider | สร้างไฟล์ใน `js/ai/` ที่ export `rate` และ `generate` แล้วลงทะเบียนใน `js/ai/index.js` |
| เพิ่ม store หรือ index ในฐานข้อมูล | ต่อท้าย `MIGRATIONS` ใน `js/db.js` (ห้ามแก้ของเดิม) |

เมื่อเพิ่มหรือลบไฟล์ ให้แก้รายการ `SHELL` และเปลี่ยนเลข `CACHE` ใน `sw.js` ด้วย

## ข้อจำกัดที่ควรรู้

- คะแนนจาก AI เป็นการประเมินเพื่อพัฒนา ไม่ใช่ใบรับรอง ระดับจริงต้องยืนยันด้วยข้อสอบภายนอก (EF SET, Aptis Advanced, IELTS, Cambridge) และบันทึกผลไว้ที่แดชบอร์ดเพื่อเทียบกับคะแนนในแอป
- Rubric ในแอปเป็นเกณฑ์ภายใน ไม่ใช่เกณฑ์ทางการของ IELTS หรือ Cambridge
- รูปแบบข้อสอบใน `js/data/mocks.js` ควรตรวจกับเว็บไซต์ผู้จัดสอบอีกครั้งก่อนสอบจริง
